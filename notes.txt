        -> Assignment Operator is = (Used to Assign Value To Variable)

        -> Comparison Operators are used for comparing values and result is True/False (bool)

        -> Used in Conditional Statements 

            -> ==   !=   >  <  >=  <=

        -> Logical Operators are used for performing Logical operations 

        -> Used to check multiple Conditionals and result is True/False (bool)

                -> or: if one of the conditions is True, then result is True, otherwise False 
                -> not: negates the result, if true then false and vice versa

    -> Membership Operators

        -> Used for checking if an object is in the given sequence and result is True/False (bool)

            -> in: return True, if given object is in sequence

            -> not in: return True, if given object is not in sequence

    -> Identity Operators 

        -> Used To check if given objects are same 

            -> is: returns True, if objects are same 

            -> is not: returns True, if objects are not same 

            -> NOTE: 
                
                -> (Equality operator ==): Compares the values of two objects. 
                It returns True if their contents are the same, 
                regardless of where they are stored in memory

                -> is (Identity operator): Compares the identity (memory address) of two objects. 
                It returns True only if both variables refer to the exact same object in memory.    

    
    -> Bitwise Operators

        -> Used in Low Level Programming (010101010)

            -> & - if both bits are 1, then result is 1
            -> | - if one of the bits is 1, then result is 1

    -> Control Structures / Control Statements 

        -> Control Structures helps you determine the "flow of execution" 
        in a python program, allowing you to

            -> "make decisions"

            -> "repeat tasks"

        -> Python has given three types of Control Structures

            -> Conditional Structures / Statements (Decision Making Statements)

            -> Looping Structures / Statements (Iteration Statements)

            -> Branching Structures / Statements (Jump Statements)

        -> NOTE: TO work with Control Structures we need "Indentation" Knowledge 

    
    -> Indentation

        -> Indentation in Python is a fundamental and mandatory aspect of its "syntax", 
        used to define the structure and hierarchy of "code blocks".

        -> Unlike many other programming languages that use curly braces or keywords 
        to define blocks, Python relies entirely on "consistent" indentation.

        -> Using space as Indentation (using spaces correctly is important)

        -> Python allows for any "consistent number of spaces" or 
        a single tab(4 spaces) for indentation, the widely accepted and recommended standard.

            -> At least one space is must, but recommended is 4 space i.e tab 

    
    
    
    -> Conditional Structures / Statements (Decision Making Statements)

        -> Used to run a "block of code" based on a condition result 

        -> if 

            -> runs a block of code, if the condition is True 

                -> Syntax 

                    if condition:
                        block of code / Statements

        
        -> if else

            -> runs a block of code, if the condition is True 
            runs another block of code, if the condition is False 

                -> Syntax

                    if condition:
                        statements
                    else:
                        statements

    -> match case 

        -> The match case statement was introduced in python 3.10 for "Pattern Matching"

        -> In other language like java we have switch case 

        -> NOTE: Use elif when you are making decisions based on conditions 

            -> Marks, Age Eligibility, Salary Checks etc

        -> NOTE: Use match-case when you are selecting one option from many fixed choices 

            -> ATM Menu, Day Of Week, Months Name etc 

        -> Syntax 

            match pattern:
                case pattern_1:
                    statements
                case pattern_2:
                    statements 
                case pattern_3:
                    statements
                case _:
                    # default statement
