    -> Python is Dynamically Type Checked Language & Garbage Collected

        -> Dynamically Type Checked Language

            -> We Have a concept called "Data Types"

                -> Data Types: Categorization Of Data

                    -> Text, Whole Numbers, Decimal Numbers etc 

            -> NOTE: Dynamically Type Checked Language means, we don't need to Specify 
            Data Types 

                -> product = "iphone"
                -> price = 60000
                -> rating = 4.5 
                -> etc   

        -> Static Type Checked Language (java)

            -> NOTE: Static Type Checked Language means, we need to Specify 
            Data Types mandatory 

                -> String product = "iphone"
                -> int price = 60000
                -> double rating = 4.5 
                -> etc  

            
        -> Python is Garbage Collected

            -> Garbage collected means Automatically remove "Unused" Data 

            -> Python Automatically Cleans Up "Unused" Data from Memory / RAM 

                    product = "iphone"
                    price = 120000
                    rating = 4.6

                    print(product)
                    print(price)

                -> NOTE: Python Cleans Up rating Memory as it's never used in the program

        
        -> Interpreted Language (Python)

            -> An Interpreted Language Executes the code Line By Line 

        -> Compiled Language (Java)

            -> A Compiled Language, translates the code into Byte Code and then
            Executes all the code at once 

            -> NOTE: Performance wise Compiled Language are FASTER 

            -> NOTE: Python is world best PROTOTYPE language
