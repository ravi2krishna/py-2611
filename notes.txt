    -> range() function 

        -> The range() function in Python "generates a sequence of numbers". 
        It is commonly used for iterating a specific number of times in for loops.  

    -> range(start, stop, step): This form generates a sequence of numbers starting 
        from start (inclusive) up to, but not including, the stop value, 
        with an increment of step. The step can be positive or negative.

            range(start, stop, step)
                -> start default is 0 (included) (inclusive)
                -> stop at this value (excluded) (exclusive)
                -> step is increment (default step is 1)


    -> Nested Loops 

        -> Loops inside Loops 

        -> A nested loop in Python is a "loop placed inside the body of another loop". 
        This structure is used to handle multidimensional data (like grids or lists within lists), 
        generate patterns, and perform actions that require "multiple layers of iteration".


    -> Branching Structures / Statements (Jump Statements)

        -> Used within loops, these statements also control the flow of execution, 
        allowing you to exit a loop early (break) or skip the current iteration (continue).

            -> break: helps you exit the loops  

            -> continue: helps you skip the current iteration 

            -> pass: acts as a placeholder, does nothing

    -> Accessing Strings 

        -> Indexing 

            -> String indexing in Python allows access to "individual characters within a string" 
            using their "position", known as the "index".

            -> Python uses zero-based indexing, meaning the first character is at index 0, 
            the second at index 1, and so on.

                -> Syntax 

                    print(string[index])

            -> Positive Indexing 

                -> Starts from the beginning of string  i.e index of first character is 0

            -> Negative Indexing 

                -> Starts from the end of string  i.e index of last character is -1 

                0  1  2  3  4  5 (positive indexing)
                p  y  t  h  o  n
               -6 -5 -4 -3 -2 -1 (negative indexing)

        -> NOTE: If index is out of range, we will get index error 


        -> NOTE: To Know which object is iterable use dir() function 

            -> dir() function allows you to know what kind of operations 
            can be performed with a specific data type 

            -> if dir() shows __iter__ then the object is iterable 

        
        -> NOTE: To Know length of a specific iterable use len() function 

            -> len() function - Return the number of items in a container.

    

        -> Slicing 

            -> String slicing in Python is a method for "extracting a portion" (substring) 
            from a larger string. It utilizes the slice operator [] with specific 
            indices to define the desired segment.

            -> Syntax

                string[start:stop:step]

                -> start (optional): The index where the slice begins (inclusive). 
                    If omitted, it defaults to 0 (the beginning of the string).
                -> end (optional): The index where the slice ends (exclusive). 
                    The character at this index is not included. 
                    If omitted, it defaults to the length of the string (the end of the string).
                -> step (optional): The increment between each index during slicing. 
                    If omitted, it defaults to 1. 
                    A negative step(-1) value can be used to slice in reverse.

            -> NOTE: Similar to range() we used 

                range(start,stop,end)

    -> Functional Programming 

        -> In computer science, functional programming is a programming paradigm 
        where programs are constructed by applying and composing "functions"


    -> Functions

        -> In Python, a function is a named, "reusable block of code" that performs 
        a specific task, takes input (arguments), processes data, 
        and can return an output.


    -> Why Functions 

        -> For writing modular, organized and efficient code. 

        -> Functions can break down complex problems into smaller and
        simpler manageable sub tasks for promoting code modularity. 

        -> Once defined a function, it can be "called multiple times", so that 
        we can achieve code reusability.

    
    -> Functions are defined using "def" keyword, followed by function name,
    parenthesis(which may contain parameters), and a colon:
    the code within the function is indented 

        -> syntax

            def function_name():
                statements

            def function_name(parameters):
                statements

        -> NOTE: calling function is must

            function_name()
            function_name(parameters)

    
        -> Python functions can be defined to accept "parameters" 
        which can act as placeholders for values that will be 
        passed into function when called. 
        
            -> Values passed to the function we call them as "arguments"

            -> We use parameters to make functions dynamic in nature

    

    -> Based on arguments passed to a function, we got five Types

        -> Positional Arguments

        -> Keyword Arguments

        -> Default Arguments

        -> Arbitrary Positional Arguments

        -> Arbitrary Keyword Arguments

    

    -> Positional Arguments

        -> In Python, positional arguments are values passed to a function during 
        its call, where the assignment of these values to the function's parameters 
        is determined solely by their "order" (position) in the argument list. 

        -> The first argument in the function call is assigned to the first parameter 
        in the function definition, the second to the second, and so on. 

        -> Order Matters: If the order is incorrect, the function will receive the wrong values 
        for its intended parameters, potentially leading to errors or unexpected behavior.

    
    -> Keyword Arguments

         -> In Python, keyword arguments are a way to pass values to a function by explicitly 
        "naming the parameters" they correspond to, rather than relying on their position 
        in the argument list. 

        -> This offers advantages, primarily in terms of code readability and flexibility.

    
    -> Default Arguments

        -> In Python, default arguments allow you to define a function parameter 
        with a "pre-assigned" value i.e default value 

        -> If a caller does not provide an argument for that parameter during a function call, 
        the default value is automatically used. 
        If an argument is provided, it overrides the default.

        -> Placement Requirement: Default arguments must always be placed after 
        any non-default arguments in the function definition. 
        Attempting to place a non-default argument after a 
        default argument will result in a SyntaxError.
